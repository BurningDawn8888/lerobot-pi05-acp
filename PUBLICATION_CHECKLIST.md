# Publication Checklist

Complete this checklist before every public release.

- [ ] Source code contains no API tokens, passwords, private URLs, or personal paths.
- [ ] No dataset, model checkpoint, W&B run, log, video, calibration, or reset-pose file is staged.
- [ ] All newly added user-facing text and documentation are in English.
- [ ] `LICENSE` and `NOTICE` are present.
- [ ] Upstream attribution remains visible.
- [ ] Python source compiles successfully.
- [ ] ACP indicator fields are documented but no private dataset identifiers are embedded.
- [ ] Model and dataset repositories have their own licenses and cards.
- [ ] Real-robot safety limitations are stated in the release notes.
- [ ] The intended GitHub repository visibility is Public.
